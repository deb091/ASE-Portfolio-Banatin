# ASE Portfolio

## Course Introduction
This course covers how to build and test software that uses AI agents.
It also covers Agile development, Git, and responsible use of AI.

## Personal Learning Goals
- Use Git and GitHub to track changes in my projects.
- Test how an AI agent handles missing or incorrect data.
- Identify which actions need human approval.

## Reflection from Part A
Part A helped me see why AI agents need clear limits. In my LoRa project,
I would let the agent check sensor readings and draft alerts. The operator
would review each alert and decide what action to take.
